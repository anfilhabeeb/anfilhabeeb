I’m a software engineer and technology specialist with **20+ years of experience** across application development, system analysis, architecture, database solutions, and project delivery.

My current focus is building end-to-end intelligent systems that combine **AI/ML, computer vision, video analytics, semantic search, and edge computing**. I enjoy taking ideas from architecture and experimentation through to reliable, deployable software.

- Exploring local LLMs, vision-language models, and edge AI.
- Bringing software, hardware, and connected devices together.

- Reference-image search across historical CCTV footage.

- Computer-vision workflows for vehicle search and analytics.

- ESP32 communication and embedded-device experiments.
